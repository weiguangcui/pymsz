# Telescope presets

The numbers used by {meth}`Telescope.preset <pymsz.Telescope.preset>`, generated from
`pymsz.telescope.PRESETS`. Beams and white-noise levels are published values. Atmospheric knees
marked as approximate in the sources are approximations. The white-noise levels are in temperature
(µK-arcmin), except where another unit is given. See {doc}`../user_guide/telescopes` for how to change
them.
